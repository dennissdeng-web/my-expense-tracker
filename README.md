# 小账本 · 个人记账软件

适合手机和电脑的中文个人账本。纯 HTML、CSS、JavaScript，无第三方依赖，无需安装或构建。

## 已有功能

- 记录收入和支出，填写金额、分类、日期及备注。
- 自动统计当前自然月的收入、支出和结余；结余 = 收入 − 支出。
- 按月份或查看全部历史账单，按日期从新到旧排列。
- 删除前确认，删除后同步更新统计。
- 使用 localStorage 本地保存，刷新后仍保留记录。
- 适配 iPhone 窄屏，提供大按钮和金额数字键盘。

## 新手预览方法

1. 在 GitHub 仓库主页点击绿色 **Code** 按钮，再点 **Download ZIP**。
2. 解压下载的文件。
3. 在电脑上双击 `index.html`，用 Chrome、Edge 或 Safari 打开。保持 `index.html`、`styles.css`、`app.js` 在同一文件夹。
4. 页面打开即可使用，不需要登录、安装依赖或运行命令。

如电脑安装了 Python，也可以在项目文件夹打开终端运行：

```sh
python3 -m http.server 8000
```

Windows 可运行 `py -m http.server 8000`。在电脑浏览器打开 `http://localhost:8000`。结束时在终端按 Ctrl+C。

## iPhone 预览

推荐通过网页地址在 Safari 打开。可在 GitHub 仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择 **main** 和 **/(root)**，保存后等待 GitHub 显示网站链接，然后用 iPhone Safari 打开。

当前是私有仓库；GitHub Pages 是否可用取决于账户套餐。启用前请确认发布范围：Pages 页面可能公开访问，但账单数据只保存在各自浏览器中。此项目未自动开启 Pages 或更改仓库可见性。

如在同一可信 Wi-Fi 中使用电脑本地服务器，iPhone 可访问 `http://电脑的局域网IP:8000`，例如 `http://192.168.1.10:8000`（请换成电脑的实际 IP）。电脑须保持运行，防火墙需允许连接；测试后关闭服务器。

## 手动测试（建议按顺序）

1. 选择“支出”，输入 `20.50`，分类选择“餐饮”，日期选今天，填写“午餐”，保存。本月支出应为 `20.50`。
2. 选择“收入”，输入 `100`，保存。本月收入应为 `100.00`，结余应为 `79.50`。
3. 刷新页面，两笔记录和金额应仍在。
4. 新增一笔上个月的记录。本月统计应保持不变，历史筛选应显示上个月记录；点击“查看全部”应看到全部记录。
5. 删除记录时先点击取消，账单应保留；再次删除并确认，账单应消失，对应月的统计应更新。
6. 输入 `0`、负数或 `1.234`，应出现提示且不保存。
7. 在 iPhone Safari 查看：表单应为单列，可点击和输入，不需左右滚动。

## 数据说明

金额以整数“分”保存，避免常见小数误差。单笔金额最多 9 位整数、2 位小数，仅支持人民币。月份以设备本地日期为准，历史月份筛选不改变顶部本月统计。

数据只属于当前浏览器和当前网址，不会自动跨设备同步或上传至 GitHub。清除网站数据、使用无痕模式或换浏览器/网址可能导致看不到原账单。直接打开文件时，存储行为因浏览器而异，长期使用推荐固定网页地址和普通浏览模式。第一版未提供备份功能，请避免仅用它保存不可替代的记录。

## 项目文件

- `index.html`：页面结构。
- `styles.css`：配色、布局和手机适配。
- `app.js`：记账、统计、筛选、删除和本地保存逻辑。
